# Claude 桌面 Code 固定出口与网络检查手册

面向 macOS + Shadowrocket + 自有 WireGuard 服务器；附 iPhone 导入步骤。记录网络稳定性与隐私防护操作，不代替服务的账户、地区或金融服务准入要求。

本仓库仅含重新整理的文章、步骤、占位配置和通用检查脚本。没有真实服务器地址、设备标识、用户名、节点订阅、账号资料、原始日志、SSH/WireGuard 密钥或二维码。私有仓库也不应保存凭据。

模板需要按自己的环境填写；不要覆盖完整的现有配置。桌面 Code、终端 CLI、浏览器、手机是独立的验收对象。
