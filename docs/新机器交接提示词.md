# 给另一台 Mac 上的助手的交接说明

可把以下内容作为部署请求，先克隆并阅读此仓库：

> 请按本仓库 `docs/另一台Mac部署.md` 在这台 Mac 部署当前版本的固定美国出口与国内服务分流，并建立、验证 Claude 桌面及桌面本地 Code 的应用直连限制。先读取本机现状、保护现有配置、备份再合并。使用我通过安全本地渠道提供的现有 VPS 独立凭据，不能从仓库猜密钥，也不能擅自购买新资源。Claude绑定唯一 US-FIXED 节点；Flova、B站、飞书、抖音、小红书、WorkBuddy按域名国内直连，并合并指定DNS例外。不要关闭证书校验或复用旧机器的路径/UUID/哈希。先无账号验证，再验证真实本地Code会话；不主动提交付费生成。逐项记录配置已保存、已生效、已测试与未验收范围。仓库没有持续IP变化自动断流实现，不得声称已经具备；也没有通用CLI启动器，若需要保护终端CLI，必须另行实现和验收后才宣布覆盖。所有凭据与设备信息保存在Git仓库外，不上传。

如目标是 Windows、Linux、路由器或 iPhone，应先重新制定对应防火墙与客户端流程，不照搬 macOS LuLu 路径。
